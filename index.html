The harness that owns shared state, routes across models, verifies before it writes, and knows when to stop — loop engineering, graph orchestration, eval-driven development, cost-latency-privacy trade-offs — is the conversation I have already been having every week, in front of CIOs and at the keyboard.

Underwriting Agent Graph

A live simplified-underwriting case for a life policy: one master orchestrator, thirteen sub-agents, a harness moving work between them. The first version burned 1,151,139 tokens on a single 12-page, 5-document submission, because a loop has nowhere to put shared state and flattens into a line. Rebuilt as an agent graph — bounded nodes, one shared state each node reads and writes, shapes defined up front. Same case type: 418,209 tokens, latency per call down around 80 percent.

Company Brain

Everyone in the organisation shares one agent, and that agent knows what the company knows — without ever showing anyone a document they aren't allowed to see. Personal agents don't scale to a company; company-wide agents leak. The rule everything bends around: a chunk is only retrievable by someone the source system would show it to, excluded before ranking rather than filtered after. Built inside a fork of qm, a 117k-line multiplayer agent harness under MIT, with the permission-scoped retrieval layer as the greenfield half. H0 target: one team asking questions in Slack and getting cited answers.
